# 🎬 Netflix Movies: 1990s Exploratory Data Analysis

## About the Project

This is my first exploratory data analysis (EDA) project from my DataCamp Data Analytics and Data Science learning journey.

In this project, I explore Netflix movie data to understand more about movies released during the 1990s. I approach the dataset from the perspective of a production company interested in nostalgic movie styles and trends from that decade.

The aim is to use Python to explore the data, identify patterns in movie durations, and investigate the number of short action movies released during the 1990s.

## Objectives

- Explore the Netflix dataset and understand its structure.
- Filter movies released between 1990 and 1999.
- Identify the most frequent movie duration during the 1990s.
- Count the number of short action movies with a runtime of less than 90 minutes.
- Practise exploratory data analysis using Python and pandas.
- Use data to answer specific questions and communicate findings.

## 📂 Dataset

The project uses the `netflix_data.csv` dataset, which contains information about movies and television shows available on Netflix.

The dataset includes the following columns:

| Column | Description |
|---|---|
| `show_id` | Unique ID of the show |
| `type` | Type of content, such as a movie or TV show |
| `title` | Title of the show |
| `director` | Director of the show |
| `cast` | Actors featured in the show |
| `country` | Country of origin |
| `date_added` | Date the show was added to Netflix |
| `release_year` | Year the show was released |
| `duration` | Duration of the movie in minutes |
| `description` | Description of the show |
| `genre` | Genre of the show |
