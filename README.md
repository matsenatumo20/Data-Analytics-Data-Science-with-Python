# Data Analytics & Data Science with Python

Welcome to my learning repository! 👋

I created this repository to document my learning journey as I work through DataCamp's **Data Analyst in Python** and **Data Scientist in Python** courses.

I am interested in data, technology, AI and research, and I want to develop the practical skills needed to use data to solve problems, identify patterns and support better decision-making.

Since both learning paths cover some of the same concepts, I decided to bring my projects together in one repository. This will help me keep track of what I am learning, practise my skills, and build a portfolio of projects as I progress.

## 🎯 My Learning Goals

Through these courses and projects, I aim to:

- Improve my Python programming and problem-solving skills.
- Learn how to clean, organise and analyse datasets.
- Explore data using statistics and exploratory data analysis (EDA).
- Create visualisations that communicate findings clearly.
- Develop a better understanding of statistical methods and hypothesis testing.
- Learn how to prepare data for machine learning.
- Explore predictive modelling and evaluate model performance.
- Apply what I learn to practical datasets and real-world questions.
- Build a portfolio that reflects my progress in data analytics and data science.

## 📚 What I Am Learning

### 1. Python Fundamentals

Building a foundation in Python and learning how to use it to work with data.

Topics include:
- Variables, data types and operators.
- Lists, dictionaries and other data structures.
- Conditional statements and loops.
- Functions and reusable code.
- Working with Python libraries.
- Writing readable and organised code.

### 2. Data Manipulation and Cleaning

Learning how to prepare datasets before carrying out analysis.

Topics include:
- Importing data from files and other sources.
- Working with pandas DataFrames and Series.
- Selecting, filtering and sorting data.
- Handling missing and inconsistent values.
- Identifying and managing duplicate records.
- Creating and modifying columns.
- Grouping data and calculating summary statistics.
- Combining datasets using joins and merges.
- Working with NumPy for numerical operations.

### 3. Exploratory Data Analysis (EDA)

Learning how to investigate a dataset, understand its structure and identify useful patterns before drawing conclusions.

Topics include:
- Understanding data types and dataset structure.
- Calculating descriptive statistics.
- Exploring distributions and relationships between variables.
- Identifying trends, outliers and unusual observations.
- Comparing groups within a dataset.
- Using summary statistics to answer analytical questions.
- Communicating findings based on the available evidence.

### 4. Data Visualisation

Learning how to present data in a way that makes patterns and findings easier to understand.

Tools and topics include:
- Matplotlib.
- Seaborn.
- Bar charts, histograms and scatter plots.
- Distribution plots and comparisons between groups.
- Customising chart titles, labels and axes.
- Choosing appropriate visualisations for different questions.
- Using charts to communicate analytical findings.

### 5. Statistics and Hypothesis Testing

Developing my understanding of statistics and how it can be used to investigate questions using data.

Topics include:
- Measures of central tendency and variability.
- Probability and statistical distributions.
- Sampling techniques.
- Confidence intervals and statistical inference.
- Formulating null and alternative hypotheses.
- Hypothesis tests, including t-tests and chi-square tests.
- Interpreting p-values and statistical evidence.
- Understanding the difference between statistical significance and practical importance.

### 6. Data Science and Machine Learning

Exploring how statistical techniques and machine learning can be used to understand data and make predictions.

Topics I am working towards include:
- Preparing data for machine learning.
- Feature selection and feature engineering.
- Splitting data into training and test sets.
- Understanding supervised and unsupervised learning.
- Exploring classification and regression.
- Training models using scikit-learn.
- Evaluating model performance.
- Understanding overfitting and generalisation.
- Interpreting model results and recognising limitations.

### 7. Working with Different Data Sources

Learning how data can be imported, combined and analysed across different sources.

Areas of interest include:
- Reading CSV and other supported file formats.
- Working with structured datasets.
- Combining information from multiple tables.
- Introduction to SQL and relational databases.
- Understanding how data is organised and accessed.

### 8. Version Control and Project Documentation

Learning how to organise and document my work so that projects are easier to understand, reproduce and improve.

Topics include:
- Using Git and GitHub to manage projects.
- Organising notebooks, scripts and project files.
- Writing README files and documenting methods.
- Recording findings and explaining analytical decisions.
- Improving projects as I learn new techniques.

## 🛠️ Tools and Technologies

## 💡 My Approach to Learning

I want to understand not only how to write code, but also why a particular method is appropriate for a problem.

When working on a project, I aim to:

1. Understand the question I am trying to answer.
2. Inspect and prepare the data.
3. Choose suitable analytical methods.
4. Carry out the analysis and create relevant visualisations.
5. Interpret the results and explain what they mean.
6. Document limitations and possible improvements.

I am also interested in responsible data use, data quality and making sure that conclusions are supported by evidence rather than assumptions.
